# Repaso de operaciones combinadas · 4.º de Primaria

Material interactivo para repasar el orden de las operaciones (paréntesis → multiplicaciones → sumas y restas), resolverlas con la técnica del **arbolito** y convertir problemas en operaciones combinadas.

## Contenido

Siete niveles que se desbloquean en orden:

1. Recuerda el orden
2. Arbolito sin paréntesis
3. Arbolito con paréntesis
4. Piensa y corrige (verdadero/falso, paréntesis y signos)
5. Del enunciado a la operación
6. Problemas paso a paso
7. Reto final

## Uso

Abre `index.html` en cualquier navegador o publícalo con **GitHub Pages** (Settings → Pages → rama `main`, carpeta `/root`).

No se recoge ningún dato personal: el progreso solo se guarda en el navegador del propio dispositivo.
